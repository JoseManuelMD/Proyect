# Visualizador de Ordenamiento en Listas Ligadas

Un programa interactivo en Python que visualiza cómo funcionan 5 diferentes algoritmos de ordenamiento utilizando listas ligadas.

## Características

- **5 Algoritmos de Ordenamiento:**
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort

- **Visualización en Tiempo Real:**
  - Histogramas ASCII que muestran cada paso del ordenamiento
  - Control de velocidad (lenta, media, rápida)
  - Conteo de movimientos realizados

- **Arquitectura Modular:**
  - `algorithsm` - Funciones
  - `utils` - utilidades
  - `linked_list_base.py` - Clase base de lista ligada
  - `sorting_algorithms.py` - Implementación de algoritmos
  - `main.py` - Menú principal e interfaz
